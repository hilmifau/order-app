📋 Instruksi Setup

  1. Design Assets: Gunakan Canva, Figma, atau tool design lainnya
    • Logo: Gunakan emoji 🛒 atau custom design dengan warna #FFD700
    • Splash Screen: Display logo di tengah dengan text "Order App"
  2. Export sebagai PNG: Pastikan background transparan untuk icon, solid color untuk splash
  3. Simpan ke folder: Copy ke assets/images/
    • icon.png - Logo aplikasi
    • splash-screen.png - Splash light
    • splash-screen-dark.png - Splash dark
    • android-icon-*.png - Android icons
  4. Generate splash: Jalankan npx expo-splash-screen-generate
  5. Test: Run npm start atau npm run web
